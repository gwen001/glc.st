Une formation intensive de deux jours destinée aux professionnels possédant des
bases solides en sécurité web. Elle explore les vulnérabilités avancées et permet aux
participants d'acquérir les compétences nécessaires pour __identifier__, __exploiter__ et
__atténuer les problèmes de sécurité complexes__ des applications web.

## Public cible:
- Développeurs web
- Administrateurs système
- Ingénieurs Dev(Sec)Ops
- Passionnés de cybersécurité


## Objectifs pédagogiques:
- Identifier et exploiter les vulnérabilités web avancées
- Comprendre des vecteurs d'attaque complexes comme SSRF, XXE et la pollution de prototype
- Évaluer les risques liés aux composants tiers et à l'infrastructure
- Appliquer des pratiques de codage sécurisé pour atténuer les menaces réelles


## Pré-requis:
- Connaissances de base en développement web (HTML, CSS, JavaScript)
- Familiarité avec les protocoles web (HTTP, HTTPS)
- Expérience avec les outils en ligne de commande
- Familiarité avec les vulnérabilités web de base (XSS, CSRF, SQLi...), [voir la formation cybersécurité débutant](/fr/formations/hacking-et-securite-application-web/)


## Programme:
#### Day 1
- Injection CRLF
- Bugs de second ordre
- Pollution de prototype
- _postMessage_
- Server-Side Request Forgery (SSRF)

#### Day 2
- Confusion de dépendances
- Prise de contrôle de sous-domaines
- Sécurité des jetons Web JSON (JWT)
- Injection d'entités externes XML (XXE)
- Sécurité des e-mails
