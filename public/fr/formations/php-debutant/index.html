PHP débutant

Une formation complète de 3 jours conçue pour les débutants souhaitant créer des applications web dynamiques avec PHP. Les participants apprendront à écrire du code PHP structuré, à gérer des données avec SQL et à intégrer des bibliothèques externes avec Composer. La formation privilégie l’apprentissage pratique par des exercices progressifs, aboutissant au développement d’une application web fonctionnelle. À l’issue de cette formation, les participants seront capables de concevoir et de développer le côté serveur d’un site web, en générant le code nécessaire au front-end. Cette formation est idéale pour les développeurs débutants souhaitant créer des applications ou des services basés sur le langage de programmation PHP.



Télécharger le programme (pdf)

Public cible:

  • Débutants en développement web
  • Aspirants développeurs back-end
  • Toute personne intéressée par PHP/MySQL pour créer des sites web dynamiques

Objectifs pédagogiques:

  • Comprendre la syntaxe PHP et les concepts de base de la programmation
  • Créer des pages web dynamiques avec PHP et HTML
  • Gérer les données avec MySQL et les requêtes SQL
  • Traiter les formulaires et les entrées utilisateurs de manière sécurisée
  • Structurer le code avec des fonctions
  • Utiliser Composer pour gérer les bibliothèques et dépendances PHP

Pré-requis:

  • Connaissances de base en HTML et CSS
  • Familiarité avec les navigateurs web et les éditeurs de texteCommenterSurligner
